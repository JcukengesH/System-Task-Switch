# Number-Letter Task — Godot-версия (терминал 90-х)

## Как открыть
1. Установите Godot **4.x** (проект писался для стабильной ветки 4.3+, подойдёт и 4.2).
2. Godot → Import → выберите `project.godot` в этой папке.
3. Нажмите Play (F5). Главная сцена — `scenes/Main.tscn`.

## Структура
- `project.godot` — конфиг проекта
- `scenes/Main.tscn` — вся сцена: сетка из 4 "квадрантов", таймер, комбо, кнопки, модалка результата
- `scripts/main.gd` — вся игровая логика (1:1 портирована из исходного JS: режимы, комбо-пороги, модификаторы, бонусы времени, условия победы/поражения)
- `scripts/item_display.gd` — отрисовка содержимого квадранта (буква+цифра, фигуры через `_draw()`, слово Струпа)

## Что изменилось визуально
- Чёрный фон, белый текст, белые рамки — классический терминальный стиль. Шрифт — системный моноширинный (Courier New / Consolas / DejaVu Sans Mono, в зависимости от того, что есть в ОС).
- Кнопки и модальное окно — чёрные с белой рамкой, инверсия (белый фон/чёрный текст) при наведении/нажатии — как курсор в старом терминале.
- Эмодзи заменены на ASCII-обозначения (`>`, `[ ]`, `OK`, `X` и т.д.), чтобы не выбиваться из стиля.

## Игровые адаптации (важно)
- **"Красный" символ в режиме букв** (сигнал инверсии правильного ответа) заменён на **реверс-видео** (белый фон / чёрный текст в квадранте) — сама механика инверсии полностью сохранена, просто индикатор теперь монохромный, а не цветной.
- **Тест Струпа остался цветным**, как вы и просили — используется реальный цвет (включая чёрный и белый). Для тёмных цветов на чёрном фоне добавлена белая обводка текста, иначе слово было бы не видно — на логику теста это не влияет, цвет остаётся тем же.
- Стрелка инверсии (↔) в тесте Струпа заменена на ASCII `<->`.

## Управление
- Кнопки `1` / `2` на экране, либо клавиши `1` и `2` на клавиатуре.

## Логика (без изменений от оригинала)
- Комбо 0–99: режим "буквы+цифры", 100–199: "фигуры", 200–299: "Струп", 300+: "мастер-режим" (случайно все три).
- Ошибка на комбо ≥300 — мгновенное поражение. Комбо 400 — победа.
- Модификаторы (случайный квадрант, отражения, инверсия, "сломанные" элементы-помехи и т.д.) появляются по тем же порогам комбо, что и в оригинале.
