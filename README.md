# System Task Switch — «TERMINAL PROTOCOL» (Godot 4)

Терминальный мини-гейм в стиле рабочих ПК 90–00-х: вы — оператор засекреченного
проекта **IMPERATOR**. Каждая «смена» — проверка входящих символов на четырёх
квадрантах экрана. Две кнопки ответа, таймер на каждый вопрос и комбо-рейтинг
до 400. Всё оформлено как монохромный CRT-терминал: ASCII-рамки, реверс-видео,
гудки динамика и шум сбоев.

## Как открыть
1. Установите **Godot 4.x** (проект ведётся на 4.7; на 4.3+ тоже запускается).
2. Godot → Import → выберите `project.godot` в этой папке.
3. Play (F5). Главная сцена — `scenes/Main.tscn`, вся логика живёт в ней.

## Геймплей
- На одном из четырёх квадрантов появляется символ; нужно ответить одной из двух
  кнопок, пока не истёк таймер (**15 с** на вопрос, **+1 с** за верный ответ,
  потолок 30 с).
- Верные ответы копят **комбо**. Цель смены — **комбо 400** (победа).
- Прогресс смены = комбо / 400.

### Этапы (модули)
Режимы не включаются «сами по себе» — каждый после первого покупается в магазине
(см. мета-прогрессию). Внутри этапа работают пороги комбо:

| # | Этап | Внутренний ключ | Комбо | Что проверяем |
|---|------|-----------------|-------|---------------|
| 1 | **HEX-CYPHER** | `letters` | 0–99 | гласная/согласная, чётная/нечётная; жирный символ инвертирует ответ |
| 2 | **POLYMETRY** | `shapes` | 100–199 | фигуры: считаем грани (бывшая «красная» буква стала реверс-видео) |
| 3 | **STROOPTEST** | `stroop` | 200–299 | классический Струп: слово vs цвет (тест остался цветным) |
| 4 | **THE SEQUENCE** | `master` | 300–400 | случайный режим из трёх. **Ошибка = мгновенный проигрыш, байтов не даёт** |

### Модификаторы (по порогам комбо)
- HEX-CYPHER: случайный угол (20), переворот символа (40), инверсия ответа (60), сбой-помехи (80).
- POLYMETRY: пропущенная грань (120), мат-пример вместо цифры (140), две фигуры (160), помехи (180).
- STROOPTEST: инверсия (220), переворот (240), перемешанные буквы (260), помехи (280).

При появлении нового модификатора показывается ненавязчивый терминальный попап
с инструкцией — он не перекрывает квадранты и не перехватывает ввод.

### Ошибки и финалы
- Допуск ошибок по умолчанию **0** (первая ошибка — провал). Покупается до 3.
- Дошли до непровиденного (некупленного) этапа — **позитивная концовка смены**
  с зарплатой; дальше — в магазин за следующим модулем.

## Мета-прогрессия
Верные ответы капают валюту **BYTES** (HEX-CYPHER +1, POLYMETRY +2, STROOPTEST +3,
THE SEQUENCE +0). На них в магазине **SYSTEM UPDATE** (из главного меню или прямо
с экрана поражения) покупаются:

- **Этапы**: POLYMETRY 150 / STROOPTEST 400 / THE SEQUENCE 900 B.
- **Допуск ошибок** (терпимость к промахам): 100 / 300 / 700 B за уровни 1–3.
- **Откат** (что происходит со счётом после ошибки): в начало игры / в начало
  этапа / −20 очков / без отката — 350 / 600 / 1200 B.
- **Пропуск** (старт смены сразу с этапа): 500 / 900 / 1500 B; требует, что
  следующий этап куплен и в предыдущем набрано **300 очков за всё время**.

Всё это — в `scripts/meta.gd` (единый источник правды по ценам) и сохраняется в
`user://terminal_settings.cfg` вместе с настройками управления.

## Управление
- **Ответ 1 / Ответ 2** — по умолчанию клавиши `1` и `2`, переназначаются на
  **любые клавиши и кнопки мыши** (ЛКМ/ПКМ/колесо/боковые) в CONFIGURATION.
- `F4` — пауза, `Esc` — прервать смену.
- Во всех терминальных экранах — навигация **W/S + Enter** и **мышью**
  (наведение + клик, колесо — листание).
- `F3` — отладочное меню (только в debug-сборке).

## Структура
- `project.godot` — конфиг; автозагрузка `SFX` (озвучка).
- `scenes/Main.tscn` — единственная сцена: сетка квадрантов, таймер, комбо-бар,
  HUD байтов/прогресса, оверлеи ошибок.
- `scripts/main.gd` — оркестратор (528 строк): ввод, состояния `State`, связывание
  модулей и экранов, фасады публичного контракта (`start_game`/`handle_answer`/
  `end_game`) и read-only свойства для live-проб.
- Модули той же папки (`RefCounted`, состояние игры — не в `main.gd`):
  `session_rules.gd` (385) — правила забега: таймер, комбо, ошибки/допуск/откат,
  этапы и модификаторы, экономика байтов; `session_presentation.gd` (186) —
  витрина забега: квадранты, индикаторы HUD, баннеры, фидбек; `hud_builder.gd`
  (281) — построение HUD-нод (сетка F3 debug-меню — в `debug_menu_ui.gd`, 106);
  `fx_director.gd` (255) — CRT, аудио-реактивные слои,
  VU, тряска; `screen_router.gd` (123) — коммутация экранов; `settings_io.gd` (118) —
  `user://terminal_settings.cfg`.
- `scripts/meta.gd` — каталог мета-прогрессии (цены, курсы, дефолты).
- `scripts/item_display.gd` — отрисовка квадранта (буква+цифра, фигуры через
  `_draw()`, слово Струпа).
- `scripts/screens/` — терминальные экраны: `boot_screen`, `main_menu`,
  `config_menu`, `help_screen`, `system_update` (магазин), `shift_complete`
  (позитивная концовка), `lose_cutscene` (провал + мини-меню с кнопкой в магазин),
  `end_cutscene` (финал), база `terminal_screen`.
- `scripts/sfx.gd`, `scripts/stat_bar.gd` — звук и полоски-статусы.
- `shaders/crt.gdshader` — CRT-фильтр (развёртка, виньетка, шум).
- `fonts/HomeVideo-*.otf` — терминальный шрифт; `audio/` — музыка по этапам и сэмплеры.
- `STYLE.md` — свод стиля «90-е/00-е терминал»; `docs/` — дизайн-спеки.
- `.import`-файлы рядом с ассетами — метаданные импорта Godot, **нужны в репо**.
